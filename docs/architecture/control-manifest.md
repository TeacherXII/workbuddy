## 1. 渲染 / 光照硬约束（来自美术 §3）

| 编号 | 约束 | 上限 / 取值 | 说明 |
| --- | --- | --- | --- |
| R-01 | 主渲染器 | **Forward+（Vulkan）** | 低配回退 Compatibility（GL），关体雾/动态GI |
| R-02 | 动态点光同屏 | **MVP ≤12 / Tier2 ≤32** | Forward+ 聚类；超 32 触发断言 |
| R-03 | 投影光数量 | **≤1（月光 DirectionalLight3D）** | 守卫提灯 OmniLight 默认 `shadow=false`；高端预设可 +最近 1–2 提灯 |
| R-04 | 体积雾密度（base） | **≤ 0.05** | 冷调染色 `#10141C`/`#3E5C76`；禁暖雾主导 |
| R-05 | 熄灯过场雾 ramp | **≤ 0.12 且持续时间 ≤ 0.4s** 后回落 | 美术 §3.3「黑暗吞没」 |
| R-06 | 静态几何 GI | **LightmapGI 烘焙**（每区域一次） | 动态物体不进烘焙 |
| R-07 | 动态光构成 | 仅 可互光源 + 守卫提灯 + 少量彩窗 SpotLight | 静态大光池走烘焙，非实时 |
| R-08 | 尘埃加法粒子 | 每光柱上限 + **全局 additive 上限**（建议 ≤ 2000） | 仅光柱/点光内可见；CI 断言 |
| R-09 | 目标帧率 | **60fps @ 1080p**（GTX1060 档） | 画质预设 低/中/高 |

## 7. CI / 构建期静态断言（建议）

- 编辑器导入/构建脚本校验：场景中实时 `OmniLight3D`/`SpotLight3D` 同屏 **> 32** → 警告（R-02）。
- 体积雾 `volumetric_fog_density` **> 0.05** base 或 ramp **> 0.12 / > 0.4s** → 警告（R-04/R-05）。
- 静态网格缺 UV2 → 警告（ADR-004 LightmapGI 前置）。
- 同屏声环实例 **> 8** → 警告（G-02）。
- 暴露脉动 shader 频率参数 **> 2Hz** → 警告（V-02）。

> 任何告警不阻断构建（lean 评审），但须在评审记录「漂移」并获主理人裁决。
