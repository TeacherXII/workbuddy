# 游戏概念文档（Game Concept Document）

- **项目代号**：ASHEN STEP《灰烬之步》
- **引擎**：Godot 4
- **平台**：PC / Steam（键鼠 + 手柄）
- **评审强度**：lean（仅核心节点卡质量门）
- **范围**：小而精（约 3–8 小时流程，多周目 / 多路线支撑）
- **文档版本**：v0.2（Phase 1 锁定版）
- **Phase 1 锁定**：概念文档 + 美术圣经双交付完成；相机框架已定。
- **作者**：文策渊（设计策略师）

## 0. 一句话 Elevator Pitch

引导一名被诅咒的潜行者，在沉没的哥特要塞中**一步一步**丈量黑暗——读巡逻、控光影、掷声响，把每一次落足都变成一场有质感、可回味的精密潜行。

---

## 1. 游戏支柱（Pillars）

### 支柱一：步步为营（Deliberate Motion）
- **定义**：每一个移动都是一次「可读、可权衡、带即时反馈」的承诺；游戏奖励规划，而非反应。
- **为何成立**：这是用户锁定的核心手感诉求（谨慎规划、每一步都有权衡与明确反馈）。它把本作从「动作潜行」中抽离，形成与参考作 *Shadow Gambit* 不同的差异化节奏，也是后续所有机制的统一标尺。

### 支柱二：感官愉悦（Sensory Craft / Sensation）
- **定义**：流畅、有重量、带质感的操控与视听反馈，让一次干净利落的潜行本身成为一种享受。
- **为何成立**：用户最想「偷走」的体验正是 *Shadow Gambit* 的 Sensation——华丽、流畅、有质感的操作与反馈。它是本作在压抑基调中仍然让人上瘾的钩子。

### 支柱三：自主掌控（Owned Agency / Autonomy）
- **定义**：路线、工具、解法都允许多种可行方案；不存在被脚本写死的「唯一正解」。
- **为何成立**：用户心理动机主轴是 Autonomy——自由选择、自由规划。多解带来重玩价值，也让「步步为营」的规划感真正成立（玩家在规划**自己的**方案，而非执行设计师的方案）。

### 支柱四：肃穆压迫（Oppressive Stillness）
- **定义**：用光、声、空间与细节营造「被注视的寂静」——沉浸、压抑而庄重。
- **为何成立**：题材为黑暗奇幻，情绪基调为 immersive / oppressive。它是世界观的落地方式，也是让 Sensation 有对比、有重量的必要底色（没有黑暗，光就不珍贵）。

> **支柱互锁**：Deliberate Motion 是方法，Sensory Craft 是奖励，Owned Agency 是自由，Oppressive Stillness 是氛围。任何新增机制若违背任一支柱，应在评审中标注「支柱漂移」。

## 2. 相机框架（Camera Framework）

- **相机类型**：高角度俯视 / 等距固定机位（约 45–60° 俯角）。相机为**固定机位**，不随角色旋转或跟随摇移；玩家读的是「整张场地」，而非角色背后的第三人称视角。
- **选择理由**：
  1. **全局潜行可读性**：贴合 *Shadow Gambit* / *Curse of the Dead Gods* 的俯视潜行传统——守卫锥、路径、掩体在同一俯视画面内一眼尽收，规划不必靠镜头追人。
  2. **地面语言需要俯视**：本作潜行词汇是「光池—阴影织锦」的地面对比（见 §6 视觉锚点意象 4）；只有俯视才能让光池、声波环、足迹残影在同一平面上「一眼可读」，形成读图式潜行。
  3. **棋手式规划感**：固定俯视天然带来棋盘 / 沙盘的俯瞰感，与支柱一「步步为营」的落子式规划同构——玩家像在下盲棋，而非被第一人称反应牵着走。
- **与美术圣经的吻合声明**：本文相机框架与 `design/art/art-bible.md` §0 的相机假设（高角度俯视 / 等距，约 45–60° 俯角）**完全一致**；美术圣经据此定的剪影可读性、HUD 屏占比与可读色系**无需返工**。
- **对玩法的影响**：
  - 俯视下，**视野锥 / 光池 / 声波环均为世界内（in-world）、俯视可读**的平面要素，不依赖任何镜头切换或俯仰动作即可判读。
  - **RTwP 凝神时相机不旋转、仅压暗**：进入「凝神 / 聚焦」慢动作预览时，机位保持不动，仅整体压暗四周、提亮可读要素，以强化「读场」而非「转场」——读的是布局，不是镜头。
  - 落足足迹残影（ghost-trail）在俯视平面上天然清晰，支撑「潜行即表达」（见 §3 MDA 分析的 Dynamics）。

## 3. MDA 分析

### M — Mechanics（核心机制）

本作**只把一条核心系统做到极致**：**「读—步」（Read & Step）潜行循环**。围绕它拆出以下具体子系统（均服务于同一循环，不新增平行大类）：

1. **步进提交（Step-Commit Movement）**
   - 采用**实时 + 可暂停（RTwP）**模型：时间常驻流动，按住「凝神 / 聚焦」键进入慢动作预览，松开即提交下一步。
   - 移动以「落足点」为单位呈现：每次提交在地面留下淡淡**足迹残影（ghost-trail）**，落足瞬间给出触觉级音效（咔 / 嗒），让「一步」成为可感知的实体。
   - *设计红线*：不做爽快连击式位移；每步之间必须有「读」的间隙。

2. **视野系统（Vision Cones）**
   - 守卫拥有可视锥 + 真实 LOS（遮挡判定）。
   - **光影敏感度**：守卫在亮处看得远、在暗处视野收缩；玩家身处阴影时等效「不可见」，但踏入光池会被立即纳入锥内。
   - 锥体以高对比颜色呈现（见 §6 视觉锚点），并提供「即将扫到你」的**预警 tell**（锥缘轻微脉动）。

3. **声音系统（Sound Propagation）**
   - 脚步噪声 = f(地面材质, 移动速度)：石板 > 木地板 > 地毯 / 苔地；奔跑 / 疾走显著高于潜行步。
   - 可投掷**声响诱饵**（碎石、骨片）在落点制造可控噪声圈，引开守卫。
   - 噪声以可视化**声波环**扩散，玩家可预判波及范围。

4. **掩体与阴影（Cover & Shadow）**
   - 阴影是**可消耗资源**：藏身于阴影池、物体后；部分区域可通过**熄灯 / 遮光**主动制造阴影（互动环境物件）。
   - 掩体不是「无敌」，而是「降可见度 + 断开 LOS」。

5. **巡逻 AI（Patrol & Suspicion）**
   - 状态机：平静(Calm) → 可疑(Suspicious) → 警戒(Alert) → 搜索(Search) → 归位(Return)。
   - 可疑度是**连续条**而非二进制：玩家能从 HUD 与守卫姿态（转身、举灯、拔刃）读出「还差多少被发现」。
   - *关键*：暴露极少瞬间即死；暴露是**可见的升级**，给玩家时间补救或重规划——这正强化「步步为营」。

6. **环境互动道具（Distraction / Interaction）**
   - 小工具集（MVP 限 3–4 种）：声响诱饵、可熄光源（烛 / 灯 / 吊灯）、可触发机关（钟、落石、松动地板）、短程障目烟雾。
   - 道具克制「唯一解」：同一扇门可用钥匙、可用阴影绕行、可用声响调虎。

### D — Dynamics（涌现行为）

- **棋手节奏涌现**：玩家自发形成「暂停 → 读场 → 预想 2–3 步 → 提交 → 看反馈」的循环，像下盲棋。
- **系统叠加的临场张力**：守卫转身的瞬间你正好踏入光池——玩家即兴用诱饵补位，而非死板走位。这种「多系统咬合」的意外正是 Autonomy 的乐趣来源。
- **自主路线涌现**：屋顶 / 下水道 / 阴影侧翼各自成立，玩家形成个人风格（「我是声响流」「我是 shadow-flank」）。
- **失败可恢复**：可疑 → 警戒 → 搜索的梯度让失误变成「重新规划的机会」而非读档惩罚，巩固 deliberate 手感。
- **潜行即表达**：玩家赛后回看自己的 ghost-trail，会看到一条「属于自己」的精密路径——Sensation 在此兑现为「我做到的愉悦」。

### A — Aesthetics（目标体验）

- **主：Sensation（感官愉悦）**——干净执行的丝滑、有重量；反馈是物理的、可触的（足音、微光、尘埃），不是炫目的庆祝。
- **辅 1：Discovery（发现）**——逐步读透要塞与巡逻的「认知快感」。
- **辅 2：Challenge（挑战 / mastery）**——一次零暴露通关的满足。
- **辅 3：Immersion / Submission（沉浸 / 臣服）**——肃穆压迫让玩家「安静下来」，被世界包裹。
- *刻意规避*：纯 Sensation 而无张力会空洞；故以 Oppressive Stillness 作对比，让「光」与「安全」显得珍贵。

## 4. 核心循环（Core Loop）

**文字概述**：观察 → 规划 → 提交 → 读反馈 → 调适。世界随你的每一步推进，但你永远有「读」的余地。

**步骤描述**：
1. **扫描（Scan）**：暂停 / 慢放，读守卫锥、声音区、光 / 影分布、机关与 hazard。
2. **规划（Plan）**：选定路线 / 工具 / 诱饵；系统用足迹残影**预演下一步落点**。
3. **提交（Commit）**：松开聚焦，时间流动，守卫按 AI 行动，你真正落足。
4. **读反馈（Read）**：即时反馈——仍隐藏？制造了噪声？可疑度在升？光锥是否将扫来？
5. **调适（Adapt）**：安全则续行；暴露则借环境 / 道具降可疑或改道（非读档）。
6. **达成（Achieve）**：夺取房间 / 目标 / 出口 → 进入下一区域。
7. **元循环（Meta）**：关卡间由玩家**自选下一入侵目标 / 侧翼**（Autonomy）；重玩时换路线即新体验。

## 5. 范围分层（Scope Tiers，贴合「小而精」）

### Tier 1 — 必做（MVP，决定游戏是否成立）
- 单一核心「读—步」循环完整可玩（RTwP + 步进提交 + 足迹残影 + 提交音效）。
- 1 名潜行者；视野锥 + 光影敏感度 + 声音传播 + 掩体 / 阴影 + 可疑度状态机。
- 3–4 种干扰 / 互动道具。
- 核心 HUD：视野锥、可疑度条、光影 / 噪声指示、下一步预演。
- Sensation 级反馈：足音 foley、落足微光、提交慢动作、暴露梯度。
- 1 张精工要塞主关卡（含 3–5 个递进子区域；总流程体量由多周目 / 多路线支撑至 3–8h）。
- 存档 / 读档、基础手柄映射。

### Tier 2 — 期望（拉开质感与重玩）
- 2–3 张主题各异的关卡（地穴 / 钟楼 / 王座厅），共享同一套核心系统。
- 每关 ≥ 2 条成立路线（屋顶 / 阴影侧翼 / 下水道）。
- 2 种额外敌人原型：循声猎犬（听觉优先）、暗视哨兵（暗处仍可见，逼迫换解法）。
- 「最佳潜行」幽灵回放（ghost-trail 对比）。
- 可访问性：色盲友好锥色、可调时间缩放、可关眩晕特效。

### Tier 3 — 拓展（锦上添花，不挡发布）
- 轻量元结构：关卡选择 / 入侵「侧翼」分支（Autonomy 的元层表达）。
- 环境处决 / 机关谜题（仍用已有互动物件组合，不新增系统）。
- 新道具、照片模式、「最干净通关」排行榜。

> **范围纪律**：Tier 1 之外**不新增平行系统大类**，只用关卡几何 + AI 变体 + 物件组合来叠加深度。这是对「小而精 / 单核心做极致」的硬性约束。

## 6. 视觉锚点（供 Art Director 产出美术圣经）

> 本节刻意写「死」，便于美术圣经直接落地，不需二次猜测。

- **情绪基调**：大屠杀后的午夜大教堂——寂静、敬畏、被注视的恐惧。不是血腥炸裂，而是「空气都凝重」。
- **配色方向（具体色系）**：
  - 基底：炭灰 / 烟灰（`#1B1B1F`、`#2A2A30`）占约 70%。
  - 冷调阴影：月光蓝黑（`#10141C`、`#3E5C76`）用于阴影池与夜景。
  - 暖调光源（稀缺、珍贵）：烛琥珀（`#C8862F`）、血锈（`#7A2E2E`）仅作点状高光（≤10% 画面）。
  - 原则：**亮 = 暖且稀缺，暗 = 冷且广**；高对比让「光池」成为可读的潜行语言。
- **参考美术风格 / 游戏**：
  - *Shadow Gambit: The Cursed Crew*——形状干净、可读、painterly，作为「Sensation 清晰度」标杆。
  - *Blasphemous*——哥特怪诞的黑暗奇幻造型语言。
  - *Hellblade: Senua's Sacrifice*——雾、光、体积感的压抑氛围。
  - *Limbo / INSIDE*——剪影可读性（silhouette readability），保证潜行要素一眼可辨。
  - *Curse of the Dead Gods*——俯视潜行的光影对比参考。
- **关键视觉意象（建议做成 key art / 概念图）**：
  1. 一束冷月光中，潜行者**定格在落足中途**的孤独剪影。
  2. 破碎的彩窗后，尘埃在光柱里缓缓飘浮。
  3. 守卫的提灯在漆黑中划出一道缓慢的光弧。
  4. 地面如一幅「光池与阴影」的织锦，玩家脚步在其上落子。
  5. 一盏可被你掐灭的烛台——灭灯瞬间整间厅堂被黑暗吞没（玩法即视觉）。

## 7. 风险与权衡（已知设计风险 + 缓解）

### 风险 1：「步步为营」滑向「拖沓 / 解谜苦工」
- **成因**：过度强调谨慎规划，节奏可能变慢、像在推箱子。
- **缓解**：① 用 RTwP 而非回合制保流动感；② 每步都给丰厚、juicy 反馈（足音、微光、残影）让「慢」也爽；③ 提供「安全步」轻提示（可关）降低挫败；④ 暴露梯度让失误可恢复，避免反复读档的疲惫。

### 风险 2：Sensation 重反馈 vs 肃穆压迫 的调性冲突
- **成因**：华丽反馈可能冲淡 dread，变成「炫耀通关」。
- **缓解**：反馈走**物理 / 触觉**（foley、微光、尘埃）而非**庆祝 / 闪亮**；成功感受是「在黑暗里活下来」，不是「我赢了」；配色保持冷调，亮部稀缺。Sensation 是「质地」，不是「烟花」。

### 风险 3：单核心系统要撑起 3–8h
- **成因**：只做一条系统，内容深度靠什么堆？
- **缓解**：深度**来自关卡几何 + AI 变体 + 物件组合**，而非新系统；同一套动词在递进场景中反复重组；关卡以「空间系统」（重叠视线、多入口）模块搭建，路线自然涌现。

### 风险 4：Autonomy（多路线）vs 小而精（手工量）的成本矛盾
- **成因**：为「多解」手工铺多条路，成本爆炸，违背小而精。
- **缓解**：不做「脚本化分支路径」，而把关卡设计为**重叠视野域的空间系统**——多入口、多制高点、可互动光源天然产出涌现路线，免费获得 Autonomy。

### 风险 5（实现边界，待与程基岩对齐）：RTwP + 可视锥 + 声波 + 状态机在 Godot 的预算
- **成因**：慢动作预览、锥体重算、声波扩散可视化可能吃性能。
- **缓解**：锥体 / 声波用**事件驱动 + 空间分区**而非逐帧全图重算；慢放用时间缩放而非额外模拟；MVP 先锁守卫数量上限，待架构评审（`docs/architecture/architecture.md` / `control-manifest.md`）确认后再扩。*此条需主理人中转与程基岩核对引擎边界。*
