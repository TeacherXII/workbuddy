## 1. 计算方法与基线

- **算法**：WCAG 2.1 对比度。sRGB 相对亮度 `L = 0.2126·R + 0.7152·G + 0.0722·B`（各通道先经 `c/12.92`（≤0.03928）或 `((c+0.055)/1.055)^2.4` 线性化）。对比度 `= (L_light + 0.05) / (L_dark + 0.05)`，结果四舍五入至两位小数。
- **参考面板（深色）**：以 `#16181D` 为**权威核算基准**（用户给定「`#16181D` / `#1C1F26` 一类暗色」）。同时交叉核算 `#1C1F26`、`#1B1B1F`（美术圣经 §2.1 / GDD §2 面板基调），确认所有载体/强调色在最暗基准上都达标，故可安全用于三者任一。
- **阈值口径**（对齐 `core-hud-a11y.md` §6，并采用用户给定的 C-03 广义 WCAG 2.1 读法）：
  - **C-02**：关键指示（可疑度 / 暴露）载体文字 **≥7:1**（WCAG AAA）。
  - **C-01**：UI 正文 / 数值 **≥4.5:1**（WCAG AA）。
  - **C-03**：大字号（≥18pt 或 ≥14pt 粗）**或 UI 组件边界 / 图形对象** **≥3:1**。*说明*：GDD §6 原文把 C-03 限在世界可读要素（锥缘/落点），本签字稿对 HUD alert-state 采用 C-03 的广义读法——任何作为「UI 组件边界/图标」的红/琥珀都必须 ≥3:1。这正是 `#7A2E2E` 连作边框都不合格的根因。

## 3. 可读载体（Readable Carrier）策略

**原则**：HUD 上一切「承载可读性关键信息」的像素，统一用近白载体色 `#DCE3EC`（13.74:1，过 C-02）。红 / 琥珀**只作非文字语义提示**，绝不承载可读性关键文字或关键条主体。

**必须用 `#DCE3EC` 承载的信息（强制）**：
- 可疑度数值（眼 / ? / ! 旁的数字，C-02）。
- 暴露 ALERT 标签文字、`exposure_detected` 屏角提示的文案（C-02）。
- 道具 / charges 数值、凝神状态文字、所有 HUD 正文与菜单文字（C-01）。
- 图标**填充**：? / ! / 眼 等状态图标以 `#DCE3EC` 描边或填充，保证形状可读（C-05/C-07 三重编码之「形状」）。

**红 / 琥珀仅作（非文字语义）**：
- **边框（border）**：警报红 `#D64545` 描边、警戒琥珀 `#C8862F` 描边——仅作「状态分界线」提示，且须 ≥3:1（C-03，已核算通过）。
- **脉冲（pulse）**：暴露脉动 ≤2Hz（V-02）、幅度温和（V-01/V-03 防护）；脉动是「亮度 + 形状」提示，不靠颜色 alone。
- **图标（icon）**：! / 危险符以 `#DCE3EC` 填充 + 红/琥珀描边，三重编码（C-07 绝不单色）。
- **低不透明填充**：`#7A2E2E` 仅以低 alpha（建议 ≤0.35）作屏角/守卫处血锈**底纹**，其上是白色载体文字——可读性由白字保证，红底仅为氛围（§1 肃穆压迫，不破红线）。

**禁止**：
- 禁止用 `#7A2E2E` 写任何 HUD 文字、数值、关键条主体。
- 禁止用 `#7A2E2E` 作 C-03 边界/图标（1.91:1 不达标）；其语义角色由 `#D64545` 承接。
- 禁止引入主色板外新色相（美术 §2.4）；`#D64545` 是 `#7A2E2E` 的明度变体，合规。

## 5. 色盲模式映射（C-06 / C-07）

> **v1.1 追认改判**：v1.0 原规则「色盲模式下 Alarm → `#C8862F`」**作废**。根因：警戒 CAUTION **本就是** `#C8862F`，映射后警戒与警报**同色值、亮度比 1.00:1**，C-05 三重编码中的「亮度」维度彻底塌缩，仅剩 `?`/`!` 两个笔画级字符可辨——对「色觉缺陷 + 低视力」多重障碍玩家几乎不可区分。改判后见下表。

- **默认模式**：Tier3 警报 = 白载体文字(`#DCE3EC`) + 红边框/图标(`#D64545`) + 实心三角 `!` + **2.0Hz 双拍**脉冲。三重编码（亮度 + 形状/面积 + 频率），绝不单色（C-07）。
- **色盲模式开启（C-06）**：警报语义色 `#D64545` → 替换为 **`#F0C070`**（烛琥珀**高明度**变体）+ 图标。vs 警戒 `#C8862F` = **1.81:1**，亮度维度恢复；vs 面板 `#16181D` = **10.55:1**（连 C-02 都过）。
- **Tier2 警戒** 在两种模式下均用 `#C8862F`（本就是琥珀），靠空心圆环 `?` 图标 + **0.5Hz 单拍**脉冲区分于警报。
- **★ 关键设计约束**：**脉冲频率与图标面积编码不随色盲开关切换，而是两种模式下常驻生效。** 理由：默认模式下 `#C8862F` vs `#D64545` 亮度比仅 **1.44:1**，红绿色盲玩家**在未开色盲模式时**就已难以区分；若把频率/面积编码绑定在开关上，等于要求玩家「先知道自己需要它」才能获得它。**常驻是更诚实的默认。**
- **禁止**在色盲模式下用纯红/纯琥珀单独表意——必须配形状/图标/位置（C-05/C-07）。

### 5.1 告警色治理三件套（v1.1 追认 · 缺一不可）

| 维度 | 警戒 CAUTION | 警报 ALARM | 生效范围 |
| --- | --- | --- | --- |
| **色值（默认模式）** | `#C8862F` | `#D64545` | 亮度比 1.44:1（弱，故需下两维兜底） |
| **色值（色盲模式 C-06）** | `#C8862F`（不变） | **`#F0C070`** | 亮度比 **1.81:1**（原 1.00:1） |
| **脉冲频率** | **0.5Hz 单拍呼吸** | **2.0Hz 双拍** | **常驻**；均在 V-02（≤2Hz）内，未破 V-01（禁 >3Hz） |
| **图标面积编码** | **空心圆环** + `?` | **实心三角** + `!` | **常驻**；实心 vs 空心是**面积级**差异，小尺寸下远比 `?`/`!` 的笔画级差异可读 |
