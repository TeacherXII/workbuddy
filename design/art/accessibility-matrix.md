## 1. 三档定义（定位与启用范围）

### 1.1 Basic（合规底线 / 最低保障）
- **定位**：保证游戏**可玩**、满足基础无障碍底线。出厂即强制生效的一组硬约束，玩家无需进入设置即可受益。
- **启用范围**：对比度硬达标、亮度/边界编码、色盲三重编码（全局默认）、频闪/脉动/转场防护、屏震/动态模糊**默认关**、雾密度硬封顶、字幕默认开、键盘/手柄可达、时间缩放默认 0.25×（粗步进）。
- **覆盖**：最核心的视觉 / 听觉 / 运动障碍群体。
- **出厂默认档**：否（Basic 是「底线」，不是默认体验档；游戏出厂默认设为 **Standard**）。

### 1.2 Standard（完整可访问性 / 默认推荐）
- **定位**：美术圣经 §9 原「Standard→Comprehensive」的主体，即项目 Tier2 显式可访问性要求。覆盖大多数障碍玩家，是**出厂默认档**。
- **启用范围**：在 Basic 之上完整开启——色盲模式开关（C-06）、时间缩放完整 0.1–1.0× 细步进（T-01）、雾选项 FULL/REDUCED/OFF（V-04）、屏震可开可调（V-03）、动态模糊可关（V-05）、文本 100–150% 缩放（X-01）、完整字幕带说话者标识+音景图标（X-02）、核心动作可重映射。
- **覆盖**：绝大多数障碍玩家（低视力 / 色盲 / 听障 / 眩晕 / 运动）。

### 1.3 Comprehensive（超越标准 / 重度障碍友好）
- **定位**：在 Standard 之上为重度障碍 / 多重障碍玩家提供的增强层。所有增强**复用既有约束编号**，不新设硬约束。
- **启用范围**：在 Standard 之上增加——自定义配色主题（过 C-01/C-02，不越 §2.4）、全输入重映射、辅助落足/路径提示（复用 §8.2 预演）、时间缩放增强（细步进+锁定+显式暂停读场，不破 T-01/T-03）、降低认知负荷选项、音频线索额外可视化增强。
- **覆盖**：重度 / 多重障碍玩家（含认知与神经多样）。

> **与美术 §9 的关系**：§9 全量基线 = 本文 Standard 档要求；§9 之上列出的 Comprehensive 增强 = 本文 §2 的 Comprehensive 行；本文新增的 Basic 档 = §9 中「强制类硬约束」的显式兜底（保证即便用户不碰设置也达标）。**无任何取值被修改**，无漂移。

## 4. 视觉纪律与四支柱一致性（可访问性开关的低调处理）

- **开关本体低调**：设置菜单内的可访问性开关、辅助指示（辅助落点高亮、自定义主题 UI）沿用面板基调——半透明暗面板 `#1B1B1F`@70–85% + `#3E5C76` 细描边，**无外发光、无霓虹、无圆角糖果**（美术 §8.1）。
- **辅助落点提示**：Comprehensive 的落点高亮复用 §8.2 下一步预演语言，用 `#C8862F` **极低强度微光 + 足迹残影**，不喧哗、不破坏肃穆压迫。
- **自定义主题边界**：Comprehensive 自定义配色**仅允许在明度 / 强调色明度维度调整**，UI 强调色仍取自 `#C8862F` / `#7A2E2E` 的明度变体，且每次切换须过 C-01/C-02 自检；**禁止引入主色板外新色相**（对齐 §2.4「禁止引入色板外新色相」）。
- **可达焦点环**：键盘/手柄焦点环用 `#C8862F` 细描边（不靠颜色 alone），与 §8 / §9.4 一致。
- **眩晕防护的美术代价**：关闭体积雾（V-04 OFF）会略微削弱「空气凝重」氛围，属预期权衡；美术侧确保关闭雾时世界要素仍靠边界/图标保可读（矩阵行 7 Comprehensive），不破 §1 肃穆压迫红线。
