## 1. 整体 UX 流程（User Flow / 状态机）

### 1.1 全链路用户路径（状态机式）

```
[BOOT 启动]
   └─(引擎自检/资源流式加载, 读档/新游戏)→
[MAIN_MENU 主菜单]                         ← 石碑铭文式, 暗面板 #1B1B1F@70-85% + #3E5C76 描边
   ├─ 继续 / 新游戏 / 设置 / 退出
   └─(新游戏或继续)→
[META_INTEL 入侵侧翼 / 关卡选择]           ← Autonomy 元层 (概念 §4 元循环 / §5 Tier3)
   ├─ 玩家自选下一入侵目标 / 侧翼节点 (屋顶/阴影侧翼/下水道/钟楼/王座厅)
   ├─ 每节点显示已知/未知情报, 多解路线在 UI 上可见可选 (支柱三)
   └─(选定节点)→
[LEVEL_INTRO 关卡内·进入]                  ← ease 缓动入场 (V-06), 无硬切
   └─→ [PLAYING 游玩核心循环]
[PLAYING 核心循环 (读—步)]
   ├─ SCAN   扫描: FOCUS 凝神慢放, 读锥/光池/声环/机关
   ├─ PLAN   规划: 选落点/工具/诱饵, 足迹残影预演
   ├─ COMMIT 提交: 松开凝神→落足, 触发足音/微光/噪声
   ├─ READ   读反馈: 仍隐藏? 噪声? 可疑度升? 锥将扫来?
   ├─ ADAPT  调适: 安全→续行; 暴露→借环境/道具降可疑或改道 (非读档)
   └─(达成目标/出口)→
       ├─[ACHIEVE 达成]→ 回 META_INTEL 选下一侧翼 (元循环)
       └─[SOFT_FAIL 软失败]→ 暴露宽限 1.2s 真实时间→检查点重生→ 回 PLAYING
[PAUSED 暂停/设置]                          ← 仅菜单用完全冻结 (T-03); 凝神非暂停
   └─(继续)→ PLAYING
[SETTLE 结算/重玩]                          ← 肃穆低键, 非炫耀; 显示路径 ghost-trail 回放
   ├─ 重玩本侧翼 (换路线=新体验, 支柱三)
   └─ 回 META_INTEL
```

### 1.2 核心循环状态转移（PLAYING 内的Read&Step 子状态机）

引用 ① `StepState{IDLE, AIMING, COMMITTING, RECOVERING}`：

```
IDLE ──(按住凝神 ② FOCUS, 进入读场)──▶ AIMING
  ▲                                        │  自由调落点(移动轴/光标) + 切步态
  │                                        │  预演残影实时跟随 aim_point
  │                                   (松开凝神=提交)
  │                                        ▼
  │                                  COMMITTING ──(step_duration 内走到落点,
  │                                        │        落足触发足音+微光+噪声事件④)──▶
  │                                        ▼
  └────────────────────────────── RECOVERING ──(≥0.12s 真实时间兜底冷却, ① COMMIT_COOLDOWN_RT)──▶ IDLE
```

- **强制读间隙**：仅 `IDLE` 接受下一次提交；上一步须 `RECOVERED` 完成 → 天然杜绝连击（概念 §3 设计红线「不做爽快连击式位移」）。
- **凝神态下仍可读场与提交**：`InputEvent` 不受 `time_scale`（ADR-003），故慢放中玩家照常规划/落点/松开提交。
- **状态可读**：每一步的状态均有世界内/屏角反馈（见 §3），玩家始终知道「现在能否落下一步」。

### 1.3 关键屏幕清单（供 §3/§5 布局）

| 屏幕 ID | 触发 | 是否阻断时间 | 视觉基调 |
| --- | --- | --- | --- |
| `SCR_MAIN` | 启动后 | 阻断(PAUSED) | 石碑铭文, 暗面板, 哥特衬线标题(art §8.3) |
| `SCR_INTEL` | 选侧翼 | 阻断 | 要塞情报台(near-diegetic 地图), 节点可选 |
| `SCR_HUD` | 游玩中常驻 | 不阻断 | 世界内为主 + 边角极简摘要(art §8.1) |
| `SCR_FOCUS` | 按住凝神 | 不阻断(FLOWING→FOCUS, 非 PAUSED) | 压暗四周+提亮可读要素(art §8.4) |

| `SCR_SETTLE` | 达成出口 | 阻断 | 路径回放, 低键结算 |

## 2. 核心交互规格（最高优先级 · 对齐支柱一「步步为营」）

### 2.1 RTwP 凝神（聚焦）交互

**语义（持有/松开）** — 引用 ② `rtwp-time-model`：
- **按住凝神键** → `TimeMode.FLOWING → FOCUS`：`time_scale` 由 1.0 缓动 ramp 至 `user_focus_scale`（默认 **0.25×**，区间 `0.1–0.3`，T-02），ramp ≈ **0.15s ease**（V-06，非硬切）。
- **松开凝神键** → `FOCUS → FLOWING`：ramp 回 1.0，同时触发 ① 步进提交（落足）。
- **输入实时性**：`InputEvent` 不受 `time_scale`（ADR-003）→ 慢放中玩家仍可移动落点光标/规划/切换步态/提交。
- **完全暂停仅菜单**：`PAUSED`/`time_scale=0` 仅用于 `SCR_PAUSE`/`SCR_SETTINGS`（T-03），**不作常规玩法**。

**凝神态下「读场」的视觉与操作** — 引用 概念 §2 / ② §5 / 美术 §8.4：
- **相机不动**（概念 §2 锁）：机位保持固定高角，仅整体**压暗四周 + 轻微冷调染色（`#10141C`）**。
- **世界可读要素反而提亮**：视野锥(③)、光池/阴影(⑤)、声波环(④)、足迹残影/预演(①) 在压暗背景上更清晰 —— 「读场」时刻，UI 退后、世界上前。
- **音频**：凝神期**不变调**（防光敏/眩晕），仅全局 `lowpass + ducking` 增强凝神质感（ADR-003）；关键音不全局 `pitch_scale`。
- **粒子同步**：凝神时显式同步 `GPUParticles3D/CPUParticles3D.time_scale = current_scale`（T-04），否则尘埃/声环不与世界同速。

**时间缩放 0.1–1.0× 调节入口** — 引用 T-01/T-02：
- 设置菜单「时间缩放」滑杆，钳制 **[0.1, 1.0]**，默认 **0.25**（写入 `A11ySettings.time_scale_user`）。
- 凝神态内**临时微调**：按住凝神时滚动鼠标滚轮 / 手柄 `LB/RB`（见 §2.3）可在当前区间内即时微调凝神倍率（落盘到 `user_focus_scale`），便于不同玩家「读场」节奏。
- **可访问性替代 `STEP_PAUSE`**：设置中开启后，凝神键改为**完全冻结**（`time_scale=0`）而非慢放，服务眩晕/低敏玩家；仍属 `FOCUS` 语义，不破坏循环（T-03 / 矩阵行 10 Comprehensive + T-03）。

### 2.2 步进提交（Read & Step）交互

**落足点选择（aim）** — 引用 ① §2/§5：
- 在 `FOCUS`(AIMING) 态，落点 = `aim_point`（世界坐标）。两套瞄准模型并存：
  - **键鼠**：鼠标光标经射线投射到地面平面直接定 `aim_point`；超出当前步态 `max_step` 时预演显 **⊘ 无效图标**（非纯红，见 §3.4）。
  - **手柄**：左摇杆推动「落点光标(reticle)」；**摇杆矢量幅度 × max_step = 步长**，全推=max_step，半推=更短步（支持 <max_step 的精细落子，强化 deliberate 手感）。
- **约束**：落点须 `∈ max_step`、非实心遮挡、非守卫身位（① §2）；越界→预演显红/⊘。

**足迹残影预演（ghost-trail preview）** — 引用 ① §3/美术 §8.2/资产 `vfx_nextstep_preview` + `vfx_footstep_trail`：
- `aim_point` 处实时绘制 **ghost footprint + `#C8862F` 极低微光**（世界内，非屏框）。
- 已落足保留 `ghost_trail` 最近 **N=6 步**淡影（Tween alpha 淡出，意象④ 地面织锦）。
- **常驻可见**：不依赖玩家记忆落点（① §7「下一步预演常驻」）。

**提交确认** — 引用 ① §2：
- **松开凝神键 = 提交**（单一确认动作，零额外点击）。角色在 `step_duration` 内走到落点。
- 步态决定节奏：`SNEAK 0.55s / WALK 0.38s / RUN 0.24s`（受 `time_scale` 缩放）。
- **读间隙纪律**：仅 `IDLE` 接受提交；`COMMIT_COOLDOWN_RT ≥ 0.12s` 真实时间兜底，杜绝连击。

**落足微光 / 足音反馈的 UX 呈现** — 引用 ① §5/美术 §1 调性禁区/资产 `vfx_landing_glow` + `vfx_ash_puff`：
- **落足微光**：落地处短暂 `#C8862F` 极低强度光池（emissive quad，**非实时光**以省 R-02），≤10% 画面纪律（art §2.1）。
- **足音 foley**：触觉级「咔/嗒」按 surface 变体（石板硬/木闷/苔软），字幕带音景图标（X-02）。
- **灰烬扬起**：微量 additive 粒子（受 T-04 同步，全局 ≤2000，R-08）。
- **成功感受**：是「在黑暗里活下来」，非「我赢了」——无庆祝爆裂（art §1 调性禁区）。

## 3. HUD 布局规格（世界内优先 / near-diegetic）

### 3.1 总原则与面板基调

- **世界内优先**（art §8.1）：视野锥(③)、光池/阴影(⑤)、声波环(④)、足迹残影/下一步预演(①) **直接画在世界里**（地面光斑/锥投影/声环），不塞屏幕边框。
- **屏幕仅摘要**（art §8.1/⑧ §2）：① 可疑度 ② 当前道具/charges ③ 凝神状态 ④ 下一步落点预演可见性开关（预演本身世界内）。
- **面板基调**：半透明暗面板 `#1B1B1F`@70–85% + `#3E5C76` 细描边；**无外发光/无霓虹/无圆角糖果**（art §8.1）。字体：数值无衬线(Inter/思源黑体)，标题/叙事哥特衬线(Cinzel/思源宋体)（art §8.3）。
- **克制规范**：游玩中屏幕仅 2–3 个小面板于边角；**无居中弹窗**、无教学轰炸（见 §6）；vignette+压暗本身即「凝神状态」表达。

### 3.2 各项位置 / 编码 / 出现时机

归一化坐标 `(nx, ny)` 原点左上。相机固定俯视 → 边角布局稳定。

| 要素 | 归属 | 位置(nx,ny) | 三重编码(亮度+形状+位置) | 出现时机 | 引用/资产 |
| --- | --- | --- | --- | --- | --- |
| **视野锥·地面投影** | 世界内(③) | 守卫前方地面半透冷白 `#9FB8C9` 低不透明 | 亮度(冷白光斑)+形状(锥)+位置(地面)；**不靠色相**(C-04/C-05) | 常驻(对应守卫在视野内) | `vfx` 实体#5；V-02 |

### 3.3 屏幕摘要面板的克制规范（硬约束）

- 游玩中（`SCR_HUD`）屏幕**最多 3 个**小面板：可疑度(屏角聚合, 仅多威胁)、当前道具、凝神倍率角标。其余全部世界内。
- **禁止**：居中模态弹窗、教学 overlay、血量/分数等无关 HUD、霓虹/外发光/糖果圆角（art §8.1 红线）。
- **出现/退场**：所有 HUD 元素 ease 淡入淡出（V-06），无硬切闪光。
- **焦点可达**：菜单内焦点环 `#C8862F` 细描边（不靠颜色 alone，art §9.4）。

### 3.4 落点有效/无效 UX 编码（色盲安全）

- 有效：`aim_point` ghost footprint + `#C8862F` 微光 + **✓ 图标**（亮度+形状，非色相，C-05）。
- 无效（越界/遮挡/守卫身位）：显 **⊘ 图标** + 微光转暗/脉冲提示；**绝不单用红色**（C-07），靠亮度+形状编码。
- 预演落点亮度差 ≥3:1（C-03）。

## 4. 凝神 / 软失败 UX

### 4.1 凝神态视觉（压暗 + 提亮可读要素）

- 进入 FOCUS：四周压暗 + `#10141C` 冷调染色；视野锥/光池/声环/残影**提亮**（概念 §2 / art §8.4）；相机不动。
- 这是「读场」时刻：UI 退后、世界上前；玩家在慢放中规划下一步（支柱一）。
- 音频 lowpass+ducking 不变调（ADR-003）；粒子同步 `time_scale`（T-04）。

### 4.2 暴露 = 软失败 UX 表达（对齐 ⑥ §2 暴露梯度）

**机制**：当 `ALERT` 且目标持续 `visibility>0` 累计 **宽限 1.2s（真实时间）** → 发 `exposure_detected` → **软失败**：最近安全检查点重生，可疑度清零，守卫回 `RETURN`/巡逻（世界部分重置）。

**观众情绪管理（避免挫败）**：
- **可见的升级梯度**（非瞬死）：可疑度连续条 + 守卫姿态readable（垂灯→举灯转身→拔刃→扫灯），玩家始终知道「还差多少被发现」（概念 §3⑤）。
- **1.2s 真实时间宽限**是**补救窗口**：宽限期内可断 LOS / 熄灯 / 诱饵降 S 自救（⑥ §2）。这是「重新规划机会」而非读档惩罚（风险1 缓解）。
- **ALERT 表达**：`#7A2E2E` + 脉动(≤2Hz, V-02) + 图标 +（可关）屏震(V-03)；**绝不单色**(C-07)；色盲模式→`#C8862F` 高亮+图标(C-06)。
- **重生瞬态 `SCR_SOFTFAIL`**：肃穆低键文案「被发现 · 退回阴影」（哥特衬线，非「YOU DIED」霓虹）；画面轻 desaturate + ease 暗角收拢(V-06)，**无硬切闪光**；在检查点 calm ease-in 入场。
- **留痕助复盘**：被抓处的 `ghost_trail` 残留极淡影，提示「这一步踩错了哪」，把失败变成可学习的规划信息（支柱一巩固）。
- **无惩罚性读档**：软失败不扣进度、不弹成就挫败；保持「在黑暗里活下来」的低调基调（art §1）。

## 6. 新手引导（Onboarding）

**原则**：教会「步步为营」节奏而不破坏肃穆压迫；首关渐进式、世界内提示、**不靠弹窗轰炸**（art §8.1 克制 / 风险1 缓解）。

### 6.1 首关渐进式教学（世界内暗示，非模态）

引用 概念 §4 核心循环 + ① 步进提交 + ⑤ 光影 + ④ 声音 + ⑦ 互动物：

| 阶段 | 引入机制 | 世界内教学手法（diegetic） | 引用 |
| --- | --- | --- | --- |
| 1 | 凝神+步进 | 地面浮现一串**淡 ghost-footprint 箭头**（复用 `vfx_footstep_trail` 风格）指向一块阴影；无文字弹窗，仅「按住右键→移动光标→松开」靠极简哥特衬线提示一次 | ①/② |
| 2 | 光池 vs 阴影 | 地面光照遮罩着色器天然高对比（意象④）——玩家**看见**光池=危险、阴影=安全，无需说明 | ⑤ §2/art §3.1 |
| 3 | 噪声 | 玩家首次落足，自己脚下扩散出**声波环**（冷`#3E5C76`），直观「这一步有多响」 | ④ §5 |
| 4 | 可熄光源 | 一烛台比环境多**握柄高光**(art §4.2)，靠近浮现极简「E 熄灯」字形(非弹窗)；熄灯瞬间暗角吞没(⑤ §5) | ⑤/⑦ |
| 5 | 诱饵 | 拾得诱饵后，落点微光+声环演示「把守卫引开」 | ⑦/④ |
| 6 | 可疑度 | 远处守卫转身，其头顶**世界锚可疑度条**(眼→?)首次出现，玩家学会「读」威胁 | ⑥/⑧ |

### 6.2 低键提示语言

- 提示用**哥特衬线极简字 + 低饱和暖灰**，左对齐、大量留白（art §8.3），禁用居中炫技弹窗。
- 「安全步」轻提示（① §7，可关）：早期 assist 默认开，当 `aim_point` 在阴影且噪声不可达守卫时给 **形状/图标提示**（非纯色）；可在设置关闭以防削弱挑战（风险1 缓解）。
- 不中断时间流：提示出现于世界/屏角，**绝不暂停游戏**教学。

## 7. 三档可访问性 UX 差异（对齐矩阵行 10/15/16/17）

> 三档定义见 accessibility-matrix §1。以下为 **UX 层表现差异**，全部复用既有约束/资产，不新增硬约束。

### 7.1 Basic（合规底线 · 非出厂默认）
- UX 表现：强制硬约束全生效（对比度/亮度边界/三重编码/频闪禁限/屏震+动模糊默认关/雾硬封顶/字幕默认开/焦点环/时间缩放默认0.25×）。
- 玩家**无需进设置即达标**；仅预设键位可达（无重映射，行14）。
- 辅助落足=核心预演（① 常驻，非专属 a11y）；无音景可视化增强、无自定义主题、无认知降档。

### 7.2 Standard（默认推荐 · = 美术 §9 全量基线 = ⑧ Tier2）
- UX 表现：在 Basic 上完整开启色盲模式开关(C-06)、时间缩放 0.1–1.0× 细步进(T-01)、雾选项(V-04)、屏震可调(V-03)、动模糊可关(V-05)、文本100–150%(X-01)、完整字幕(说话者+图标, X-02)、**核心动作可重映射**(行14)。
- 世界内提示与 Basic 一致（核心预演常驻）。

### 7.3 Comprehensive（超越标准 · 重度/多重障碍友好）
- **行 16 辅助落足/路径提示**：在核心预演基础上，**安全落点高亮 + 路径提示线**（复用 `vfx_nextstep_preview`，`#C8862F` 极低微光，不喧哗、不破肃穆，art §8 红线/矩阵 §4）。
- **行 15 音频可视化增强**：在既有世界内声环上，追加**音景类型图标 + 方向指示 + 危险音环境可视化**（复用 X-02 音景图标精灵集，`ui_icon_*`，无新增约束）。
- **行 17 自定义配色主题**：UI/HUD **明度与强调色明度可调**；每次切换过 C-01/C-02 自检；**禁止引入主色板外新色相**（对齐 art §2.4）；强调色仍取自 `#C8862F`/`#7A2E2E` 明度变体。
- **行 10 时间缩放增强**：T-01 范围内更细步进 + **凝神长期锁定** + 结合 T-03 的**显式暂停读场辅助**；**明确不突破 T-01 上限 1.0× / 下限 0.1×**（矩阵 §3.4 研判）。
- **行 18 降低认知负荷**：信息密度降档 + 关键提示优先级 + 世界内要素降噪（复用 art §8.1 极简哲学）。
- **行 14 全输入重映射**：键鼠/手柄全映射 + 切换（逻辑交程基岩）。
- **视觉低调纪律**：所有 Comprehensive 增强开关/指示沿用暗面板 `#1B1B1F`@70–85% + `#3E5C76` 描边（矩阵 §4），不破坏肃穆压迫。

**设计理论红线扫描**（概念/架构评审口径）：
- **主导策略**：无——多步态/多道具/多路线使无单一最优解；凝神倍率可调防「永远最慢最安全」成唯一解。
- **经济失衡**：无——无资源经济系统，仅 charges 限量(⑦)，属范围纪律非经济失衡。
- **认知过载**：无——HUD 边角≤3 面板、世界内优先、无弹窗；Comprehensive 行18 反而降负荷。
- **支柱漂移**：无（上表）。

**一致性结论**：UX 规格与四支柱、美术 §8/§9、架构性能预算、control-manifest 硬约束、可访问性三档矩阵**全量自洽，无漂移**。
