## 2. 合成方法（PLACEHOLDER）

**这是占位音，不是最终音效设计。** 采用规格 §2.1.1 / §2.2.1 的「路径 B · 合成」的**极简化版本**：单层衰减正弦 + 线性淡入淡出。真实资产应走**路径 A（采样）**或完整的三层合成。

```
s(i) = sin(2π · f · t) · exp(−k · t) · w(i)          t = i / 48000
```

| 参数 | A-1「嗒」 | A-2「顿」 | 说明 |
| --- | --- | --- | --- |
| 频率 `f` | **1050 Hz** | **380 Hz** | 成功较高较亮、失败较低较闷 |
| 衰减系数 `k` | **28.0 /s** | **9.0 /s** | 成功快衰减（干脆），失败慢衰减（拖沓、未落地） |
| 时长 | 110 ms | 220 ms | 规格 §2.1.3 / §2.2.3 |
| 前导静音 | **4.0 ms** | **4.0 ms** | ≤ 5 ms 上限（规格 §1.6） |
| 淡入 / 淡出 `w` | 1.5 ms 线性 | 1.5 ms 线性 | 保证首尾零交叉、DC 自由 |
| 施加增益 | **−2.70 dB** | **−8.88 dB** | ★ 由 §4 的实测反解得出，不是拍脑袋 |

### 2.1 为什么首尾必须零交叉

规格 §1.6 与 art-bible §1 红线：首尾样本若不落零交叉，会产生**直流跳变 = 一次明亮的全频带咔嗒**，正是「禁止亮」的反面。实现上淡出窗写作 `w = (n−1−i)/fade`，使**最后一个样本恰好为 0**；正弦从相位 0 起振，首样本天然为 0。实测两文件首尾样本均为 **0**（§4）。

## 3. 相对响度说明（AUD-H1 的落地）

> **AUD-H1**：失败族有效响度 **≤** 成功族有效响度。度量口径 = **Max-M**（BS.1770-4 K 计权，400 ms 滑窗），首尾各补 ≥400 ms 数字静音后测量（规格 §1.5.3）。

### 3.1 ★ 等幅度会**反向**违反 AUD-H1 —— 必须按响度标定，不能按振幅

这是本批最重要的一条工程发现。两个文件若用**相同峰值振幅**渲染，实测 Max-M 为：

| 文件 | 等幅度（unity）Max-M |
| --- | --- |
| `sfx_ui_save_success` | **−16.64 LUFS** |
| `sfx_ui_save_failure` | **−12.47 LUFS** |

**失败音反而比成功音响 4.17 dB** —— AUD-H1 被直接违反。成因有二，都与"听起来更弱"的直觉相反：

1. **时长**：Max-M 是 400 ms 窗的能量平均。失败音 220 ms 比成功音 110 ms 在窗内多铺一倍能量，摊薄修正 `W = 10·log₁₀(400/D)` 相差 **3.0 dB**（+2.6 vs +5.6）。
2. **包络**：失败音衰减更慢（k=9 vs 28），波峰因数更低（9.72 vs 10.64 dB），同峰值下 RMS 更高。

K 计权对 380 Hz 的轻微衰减（相对 1050 Hz）**远不足以**抵消这 3 dB 的时长效应。

> **结论**：**「更低频 + 更闷 + 更慢衰减」不等于「响度更低」。** AUD-H1 是一条**响度**约束，只能靠实测 Max-M 反解增益来满足，不能靠音色直觉。任何后续替换资产必须重跑 §4 的度量。

### 3.2 标定结果

按规格 §2.0 的名义有序对（成功 −18.0 / 失败 −20.0，间距 **2.0 dB**）标定，实测落点：

| 族 | 资产 @ 调用方增益 | 实测有效 Max-M |
| --- | --- | --- |
| 成功族 | `save_success` @ `0.0 dB` | **−19.35** |
| 成功族 | `save_success` @ `−1.0 dB`（删除，A-3） | **−20.35 ← 族内最小** |
| 失败族 | `save_failure` @ `0.0 dB` | **−21.35 ← 族内最大** |
| 失败族 | `action_denied` @ `−3.0 dB`（A-4） | **−24.35** |

`−21.35 ≤ −20.35` ✅ **AUD-H1 成立，余量 1.00 dB**（规格要求的余量即 1.0 dB）。
两资产间距 **恰好 2.00 dB**，与规格名义值一致。

### 3.3 ⚠ 绝对响度比名义值低 1.35 dB —— 这正是规格预登记的风险 AR-1

规格 §2.0 名义值为 −18.0 / −20.0，实际落在 **−19.35 / −21.35**（**整体低 1.35 dB**，间距不变）。

原因是**真峰天花板先撞上**：本占位音的包络波峰因数为 **10.64 dB**，超出规格 §1.5.4 给成功音核算的 **9.4 dB** 预算。在 `TP ≤ −3.0 dBTP`（规格 §2.1.4 / 验收 A5）的硬约束下，Max-M 最高只能到 −19.35，**−18.0 物理上不可达**。

这与规格 §6.2 **AR-1** 的描述完全吻合：「成功音的波峰因数预算只有 9.4 dB，偏紧。若制作时起音做得比 8 ms 更快，CF 会超预算」。占位音是**瞬时起音**（无 8 ms attack），CF 自然更高。

**处置：本批选择"保真峰、降响度"**，理由：
- 偏差方向是**变安静**，不会违反任何上限约束（AUD-L1「UI ≤ 世界锚 −3.0 dB」余量反而更大）；
- **有序对关系（AUD-H1）与间距 2.0 dB 完整保留**，这是 §7.2 纪律 3 真正要守的东西；
- 占位音的绝对响度本就不该被当作最终值。

> **给真实音效设计的交接**：真资产须按规格 §2.1.3 做 **8 ms attack**（把 CF 压回 9.4 dB 预算内），届时 −18.0 / −20.0 可达。若仍不可达，规格 §6.2 AR-1 已给两条授权退路（TP 放宽到 −1.0 dBTP，或整体降到 −19.0/−21.0），**任一改动须回写音频规格**。
